# filedrop
यह बिना इंटरनेट (डेटा) के काम करता है। आप बस अपने फोन का हॉटस्पॉट (Hotspot) चालू करें और दूसरे फोन को उससे कनेक्ट करें (या दोनों को एक ही वाई-फाई से जोड़ें)। यह टूल एक QR कोड बनाएगा, जिसे स्कैन करते ही आपकी फाइलें दूसरे फोन में दिखने लगेंगी और आप उन्हें चुटकियों में डाउनलोड कर सकेंगे।
